# Talind New AI

Complete current Talind interactive sample website, covering students and parents, teachers, institutions, and training providers.

## Run locally

From the repository root:

```sh
python -m http.server 8000 --directory dist
```

Open http://localhost:8000 in your browser. No build or package installation is required.

## Included

- Four role-specific dashboards and sample profiles
- Adaptive registration, listed and custom skills, and evidence options
- Learner main and secondary requirements
- Teacher jobs and services; institution hiring, admissions and partnerships
- Training-provider learner and institutional opportunities
- Membership plans and simulated checkout
- Sponsored placements and a simulated AI skill guide

## Current status

This is a demonstration, not a production backend. Login, enquiries, checkout, and AI guidance are simulated. Selected files are not uploaded; profile changes reset on refresh. No live payment credentials, API keys, or real user records are included.

The existing Talind V1 repository and live site are separate. GitHub automatic deployment and two-way synchronization with the Sites preview are not configured.
